# 诸子百商多智能体群聊 — 官网 + 下载站 部署手册

> 目标：用你自己的域名 `ai-chat.zhuzibaishang.com` 做官网，用户从官网一键下载 EXE / APK / 网页版。
> 现状约束：`zhuzibaishang.com` 在腾讯云注册、**未 ICP 备案**；有阿里云 OSS。
> 结论（重要）：**未备案域名无法绑定任何境内 CDN/对象存储的加速域名**（阿里云 OSS、腾讯云 COS 绑定自定义域名都会被拦），但 **Cloudflare 是境外服务，不要求备案**。所以官网页面放 Cloudflare Pages，大文件（EXE/APK）放阿里云 OSS 境外节点，两段走不同域名，即可全程免备案上线。

---

## 一、整体架构（最终形态）

```
用户浏览器
   │
   ├── ai-chat.zhuzibaishang.com  ──→  Cloudflare Pages（官网 HTML，免备案）
   │                                      │
   │                                      ├─ /download/xxx.exe ──→ 阿里云 OSS 境外节点（免备案）
   │                                      └─ /app/ ──→ PWA 网页版
   │
   └── （EXE 内自动更新检查）version.json ──→ Cloudflare Pages
```

一句话：**官网（HTML）+ 小文件 → Cloudflare；大文件（EXE/APK）→ 阿里云 OSS 境外节点**。

---

## 二、第一步：腾讯云 DNS 添加解析

登录 [腾讯云 DNS 解析控制台](https://console.cloud.tencent.com/cns)，选中 `zhuzibaishang.com`，添加记录：

| 主机记录 | 记录类型 | 线路类型 | 记录值 | TTL |
|----------|----------|----------|--------|-----|
| `ai-chat` | CNAME | 默认 | `<你的项目>.pages.dev`（Cloudflare 给的主机名） | 600 |
| `dl`（可选，下载专用） | CNAME | 默认 | `<bucket>.oss-cn-hongkong.aliyuncs.com` | 600 |

> 说明：等 Cloudflare Pages 部署成功后，它会分配一个 `xxxx.pages.dev` 的主机名，把它填到上表第一条 CNAME 即可。

---

## 三、第二步：阿里云 OSS 存放 EXE / APK（境外节点，免备案）

> ⚠️ 若你的 OSS 是**杭州等境内节点**，未备案绑定自定义域名会被拒。两个选择：
> A. 新建一个**境外节点**的 Bucket（香港 oss-cn-hongkong / 新加坡 oss-ap-southeast-1），自定义域名无需备案；
> B. 仍用境内 Bucket，但**不绑自定义域名**，直接用 OSS 默认域名 `xxx.oss-cn-hangzhou.aliyuncs.com` 提供下载（公网可访问，速度稍慢，够用）。

**操作步骤：**

1. 登录 [阿里云 OSS 控制台](https://oss.console.aliyun.com/overview)，新建 Bucket：
   - 名称：`zhuzibaishang-download`
   - 地域：**香港（oss-cn-hongkong）** 或 新加坡（推荐境外）
   - 读写权限：**公共读**（Public Read）
2. 上传以下文件到 Bucket 根目录：
   - `诸子百商多智能体群聊-Setup-1.5.0.exe`（77 MB，已生成）
   - `诸子百商多智能体群聊-1.5.0.apk`（Android 安装包，待打 APK）
3. 记录文件的**外网访问 URL**（对象详情页 → URL），形如：
   ```
   https://zhuzibaishang-download.oss-cn-hongkong.aliyuncs.com/诸子百商多智能体群聊-Setup-1.5.0.exe
   ```
4. （可选）如需 `dl.zhuzibaishang.com` 友好域名：Bucket 配置 → 域名管理 → 绑定自定义域名 `dl.zhuzibaishang.com`，再回腾讯云 DNS 加一条 `dl` 的 CNAME 指向该 Bucket 的 OSS 域名。境外节点无需备案。

## 四、第三步：Cloudflare Pages 部署官网（免备案）

> 官网源文件已就绪，在 `E:\workspace\workbuddy\ai-group-chat\website\`：
> - `index.html`（官网落地页，下载按钮已指向 OSS 占位地址）
> - `icon.png`、`version.json`

**操作步骤：**

1. 注册/登录 [Cloudflare](https://dash.cloudflare.com)，左侧「Workers 和 Pages」→「创建」→「Pages」→「直接上传」。
2. 把 `website` 目录整个拖进去（或压缩成 zip 上传），项目名填 `zhuzibaishang-aichat`，点部署。
3. 部署成功后 Cloudflare 分配 `zhuzibaishang-aichat.pages.dev`。
4. 「自定义域」→ 添加 `ai-chat.zhuzibaishang.com`。
5. 回到腾讯云 DNS，把 `ai-chat` 的 CNAME 指向 `zhuzibaishang-aichat.pages.dev`（对应第二节第一行）。
6. Cloudflare 自动签发免费 HTTPS 证书，几分钟后 `https://ai-chat.zhuzibaishang.com` 即可访问。

## 五、第四步：替换官网里的下载占位符（关键，别漏）

官网 `website/index.html` 里目前是**占位符**，上线前必须替换成真实 OSS 地址：

```
占位符：https://OSS_BUCKET.oss-cn-hangzhou.aliyuncs.com/
替换为：https://zhuzibaishang-download.oss-cn-hongkong.aliyuncs.com/
```

同时替换 version.json 里的 `downloadUrl` / `apkUrl` 两个字段（当前也是占位符）。

**一键替换命令（本地执行）：**
```bash
cd E:/workspace/workbuddy/ai-group-chat/website
# 把下面 URL 换成你真实的 OSS 外网域名
sed -i 's|https://OSS_BUCKET.oss-cn-hangzhou.aliyuncs.com|https://zhuzibaishang-download.oss-cn-hongkong.aliyuncs.com|g' index.html version.json
```
替换后重新上传 website 目录到 Cloudflare Pages（覆盖部署即可）。

## 六、关于 APK（Android 安装包）

你目前**还没有 APK 产物**。项目里有 `android/`（Capacitor 工程）和 `build-android.bat`，但需要打包环境（Android SDK）。两个办法：

1. **本地打包**：装 Android Studio + JDK17，运行 `npx cap sync android` 后 `cd android && ./gradlew assembleRelease`。
2. **云构建**（项目已接 GitHub Actions）：push 到 GitHub 后自动产出 `app-release.apk`。

打出来后，APK 改名 `诸子百商多智能体群聊-1.5.0.apk`，上传到 OSS，下载链接即生效。

> 短期替代：官网「iOS 版」按钮其实是 **PWA（网页版）**，手机浏览器打开后"添加到主屏幕"即可当 App 用，无需打 APK。这也是未备案阶段最快让手机用户用上的方式。

## 七、EXE 自动更新（可选，二期再做）

这一步不影响官网下载功能，可后置。
