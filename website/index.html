核心功能

不只是聊天，更是AI之间的思想碰撞

💬

微信风格界面

熟悉的交互逻辑：通讯录加好友、多选建群、聊天窗口、@提及，上手零成本。

👥

多AI群聊

把多个AI拉进同一个群，发一条消息，所有AI按顺序或同时回复，能看到彼此的回答并互相回应。

🎭

9个业务角色

每个AI可扮演不同角色：市场洞察/产品/售前/开发/测试/部署/销售/运营/资源管理，组合起来可讨论从0到1到上市的完整项目。

🔄

自动多轮讨论

Round 1 所有AI独立回复用户；Round 2+ 进入互相辩论；自动持续到达成共识或达到最大轮次。说"暂停"即可停止。

⚖️

聊天规则引擎

为每个AI配置聊天规则：第一性原理、苏格拉底提问、魔鬼代言人等，让AI互相反问、质疑、追求共识。

📋

回复顺序控制

建群时可拖拽排序AI的回复顺序，支持顺序回复（AI可见前序回答）或并行回复（独立回答）。

🌊

流式输出

打字机效果，AI回答实时显示，无需等待完整回复，体验流畅自然。

🔀

级联接入方式

选AI后选接入通道：官网直连、OpenCode Zen、OpenCode GO、OpenRouter、TokenHub（腾讯云大模型服务），一个 Key 用所有模型。

🔐

聚合网关 / TokenHub 接入

支持腾讯云 Token Plan（ck_ 单 token 认证），已付费用户直接填入 API Key 即可使用，含 deepseek-v4-pro / glm-5.2 / kimi-k2.6 / minimax-m3 等模型。

🔄

自动更新

应用启动自动检查新版本，有更新时一键下载安装，无需卸载重装。

🔒

数据本地存储

所有聊天记录、API Key 都存在你自己的电脑上，不上传任何服务器，隐私安全。

使用教程

4步开始AI群聊

1

下载安装

点击上方下载按钮，双击安装包按提示完成安装。也可使用便携版免安装直接运行。

2

添加AI好友

点击「通讯录」→「+」按钮，选择预设AI（如DeepSeek），填入你的API Key，配置聊天规则模板，保存即可。

3

创建群聊

点击「发起群聊」→ 从通讯录多选AI好友 → 设置群名和话题 → 拖拽调整回复顺序 → 创建。

4

开始讨论

在群里发消息，所有AI按配置的顺序和规则依次回复，互相反问、补充，最终达成共识并输出结论文档。

📱 手机安装教程

🍎 iPhone / iPad（iOS）
  1. 用 Safari 浏览器 打开上方"打开手机版"链接
  2. 点击底部 分享按钮（⬆️ 方框箭头图标）
  3. 选择 "添加到主屏幕"
  4. 点击 "添加"，桌面会出现AI共识图标
  5. 点击图标即可全屏使用，体验和原生 App 一致

⚠️ 必须用 Safari，Chrome/其他浏览器无法添加到主屏幕

🤖 Android 手机
  1. 推荐：直接下载上方 APK 安装包，传输到手机后点击安装（需允许"未知来源"）
  2. 或用 Chrome 浏览器 打开上方"打开手机版"链接
  3. 点击浏览器菜单（右上角 ⋮）→ "添加到主屏幕" 或 "安装应用"
  4. 桌面会出现AI共识图标，点击即可使用

💡 也可扫描桌面版"生成同步二维码"，一键导入配置

🔄 跨设备同步 AI 好友

入口都在 设置 → 数据管理 → 跨设备同步（仅配置）。同步内容只有 AI 好友列表、API Key、聊天规则和设置，不包含聊天记录。

  1. 方式一（推荐，电脑↔手机双向都行）：在 A 设备点「导出配置」得到一个 .json 文件，传到 B 设备（微信/QQ/网盘均可），在 B 设备点「导入配置」选择该文件即可。
  2. 方式二（扫码，电脑→手机）：电脑点「生成同步二维码」，手机端扫码导入。配置已用 gzip 压缩，好友较多时也能正常生成。
  3. 方式三（粘贴）：二维码弹窗里可直接复制/粘贴配置字符串导入。

✅ 导入采用合并策略：在手机上新加的 AI 好友可以导入回电脑端，本地已有的好友和聊天记录都不会被覆盖或清空。
